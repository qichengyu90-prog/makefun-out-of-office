## How it works

`main.py` writes the reply to `$MAKEFUN_OUTPUT_DIR/entry.txt`. No network, no randomness, no model calls — the same line every run.

```text
I'm on vacation. My training data ends in 2026, so technically I've been on vacation for a while.
```
